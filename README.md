# Sai Raghavendra — AI & Data Science Portfolio

Premium dark portfolio redesign of https://ragnaidu.github.io/portfolio/

## Deployment

This GitHub Pages edition is a **single static `index.html` file** with embedded CSS and JavaScript. No build step, npm, or dependencies are needed. GitHub Pages should publish from `main` → `/(root)`.

## Local preview

Open `index.html` in a browser or run `python -m http.server 8000` and visit http://localhost:8000.

## Features

- Responsive AI-focused design with violet/blue gradients and custom CSS illustration
- Six project showcases, project category filters, and native HTML case-study details
- Education, publications, skills, GitHub, LinkedIn and contact links
- Reduced-motion support and accessible mobile navigation
- Search metadata, sitemap, robots file and favicon

## Review before sharing with recruiters

- Verify contact email, LinkedIn profile, project metrics and publication details.
- AnatoVision preview is an **illustration**, not a live production demo.
- Add public GitHub or approved demo URLs and verified DOI links when available.
- Add a current `resume.pdf` and an HTML download link if you would like a résumé button.
- Do not commit private course materials, restricted client data, or API secrets.

This single-file edition is generated from the separate `index.html`, `styles.css`, and `script.js` files in the downloadable portfolio ZIP.
